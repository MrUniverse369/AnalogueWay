# Level brief

Copy, fill what you care about, delete the rest. Only **Zone** is required; everything else the specialist works
out from the project and tells you in its plan before building.

```
Zone:            Grassy Green | Old Tomb | Sandy Dunes | Snow Temple (Japan) | new: <name>
Level name:      e.g. Greybox_Tomb_Level7 (default: Greybox_<Zone>_<next free name>)
Deliverable:     greybox concept (default) | painted level | plan only | review of an existing level
Purpose:         what this level is for: teach X, a combat gauntlet, a breather, a showcase for Y
Where it sits:   after which level, so it knows what the player can do (default: end of the zone so far)
Must include:    mechanics, enemies, hazards, rewards, set pieces
Must avoid:
Difficulty:      gentle | like the zone's references (default) | harder than <level>
Length:          short | like the references (default) | long
References:      scenes or assets to follow beyond the zone's own levels
Constraints:     e.g. no new prefabs, no shared code changes (both are the default anyway)
Testing:         full (default) | layout only | skip Unity
```

## Asking for it

> Use the level-design skill. Zone: Old Tomb. Purpose: a descent that teaches the spike rhythm before a corridor
> boulder chase. Deliverable: greybox.

The specialist replies with a plan (sections, route, encounters, rewards, the rules it is following and their
sources) and waits for a go-ahead before building, unless the brief says "build straight away".
