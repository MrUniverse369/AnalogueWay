## Request 1: title screen, Japan zone select, torii bug, boss music

### What was asked
1. **Title screen:** keep the theme, remove the grey cat, and smooth the title so it looks softer and more polished.
2. **Japan zone select:**
   - Add the warm, sunny Japan area beside the winter area.
   - Put the sunny art next to the sandy dunes.
   - Add a torii gate that Harvey walks through when crossing from the sunny side to the snowy side.
   - Find and fix the root cause of a random black line across the screenshot.
3. **Torii gate bug in Z3A1:** the gates turn grey stone correctly in Z3A2 but not in Z3A1.
4. **Boss music:** a unique track for each boss.

### What was done

**Title screen** (`Tools/Art/main_menu.py`, which regenerates `MenuBackdrop.png` and `MenuTitle.png`)
- The grey cat was a half-buried stone cat idol in the backdrop. It was removed.
- The title now has:
  - rounded letter corners and filled inner angles, so V, Y and N have smoother diagonals
  - a softer purple outline instead of near-black
  - a per-pixel colour gradient
  - a translucent shadow
- The image size is unchanged, so the menu layout didn't move.

**The black line**
- **Cause:** a large filler box above each parallax sky met the sky sprite exactly edge to edge, with no overlap. Floating-point rounding left a gap smaller than a pixel, and at some camera positions a whole row of pixels fell into it, so the camera's background colour showed through. The line's colour, #364C76, matched the camera clear colour, #314D79.
- **Fix:** each filler box now overlaps 1 to 5 units behind its sky, one sorting step back. Each sky image was first checked to be fully opaque where they overlap.
- **Scenes fixed:** Z3A2, the Japan Village, the Japan boss arena, Z4A6 to Z4A10, and the Grass boss arena.

**Torii bug in Z3A1**
- **Cause:** Z3A1's living-world gates used `ToriGateAppearanceManager`, which sets an `LBA` trigger that their animator doesn't have, so they never changed. The spirit-world gates also had a stray `ToriGateAppearanceManagerTwo`.
- **Fix:** Z3A1 was rewired to match Z3A2. Living gates now use `ToriGateAppearanceManagerTwo` (`SFA`), and spirit gates use only `ToriGateAppearanceManager` (`LBA`).
- **Tested in Play mode:** the spirit gates animate only in the spirit world, and the living gates now animate in the living world. There were no animator warnings.
- **Left alone:** the Village and Japan boss scenes have the same miswired living gate, but those scenes never switch worlds.

**Zone select, first version**
- A sunny Japan zone was added in the HNL style, with green hills, dark tree clumps, red pagodas, cherry trees and lanterns.
- A red torii sprite (`ToriiGate.png`) was added. It draws above Harvey, so he passes between the pillars with the beams over him.
- Walking through the gate plays the existing torii sound, via new `gates` and `gateSound` fields on `ZoneSelectMap`.
- The existing scene was patched rather than rebuilt, so any hand edits were kept. `ZoneSelectSceneBuilder` was updated to match.

**Boss music** (`Tools/Music/boss_themes.py`, using the shared `arcade_synth` engine)

| Boss | Track | Style |
|---|---|---|
| Grave Warden (Tomb) | `Boss_GraveWarden.wav` | D harmonic minor, 148 BPM: galloping bass, tolling bells, organ pad |
| Sandscale Scarab (Sandy) | `Boss_SandscaleScarab.wav` | E Hijaz, 156 BPM: staccato brass, double-time darbuka, ney flute climax |
| Yokai Warrior (Japan) | `Boss_YokaiWarrior.wav` | D hirajoshi, 162 BPM: koto, taiko-style toms, shakuhachi climax |
| King Mossback (Grass) | `Boss_KingMossback.wav` | E minor, 144 BPM, swung: pulse lead, e-piano, brass chorus |

- Each track loops, runs about 50 seconds, and matches the zone music's loudness (about −14 dB).
- They were imported with the same settings as the other music (Streaming, Vorbis) and assigned in each boss scene.
- `ZoneContentBuilder` now keeps the boss track when an arena is rebuilt.
- The tracks were checked for clipping and loudness but not listened to.

## Request 2: Talisman Holder, Harvey's Bag, and a 50/50 Japan map

### What was asked
1. **Talisman Holder:** six talismans in total, up to three equipped, with swapping and a choice of which are active.
2. **Harvey's Bag:** an inventory that looks like a bag, holding:
   - books, maps and other collectibles
   - power-ups and miscellaneous items
   - items bought in villages

   Talismans stay separate.
3. **Zone select:** keep the same style, but split Japan 50/50 between sunny and snowy, because the sunny side looked too small.

### What was done

**Zone select, 50/50 version**
- The sunny/snow border moved up to about y 90, splitting Japan roughly in half.
- **Sunny lower half:** sits next to the dunes and holds Z3A1 to Z3A4, three pagodas, cherry trees, lanterns, and a koi pond fed by the river.
- **Snowy upper half:** sits next to the meadow and holds the mountains, the Village and the Boss on the peak.
- The torii moved to the climb from Z3A4 up to the Village.
- Z3A1 to Z3A4 are labelled "Sunlit Shrine Road".

**The systems**
- There was no existing inventory system to reuse, so a small one was built:

| Script | Role |
|---|---|
| `Inventory.cs` | Owned and equipped talismans, item counts, and one-time rewards. Saved through `GameSession` and `SaveData`; older saves load with the starting loadout. |
| `ItemDefinition.cs` | Item assets with a category, effect and price. |
| `HNLCatalog.cs` | Catalog asset at `Assets/Resources/HNLCatalog.asset`. |
| `HarveyMenus.cs` | Builds the menus at runtime in any level with a pause menu, so scenes need no setup. |
| `MenuUI.cs` | Shared UI helpers and the view base class. |
| `TalismanHolderView.cs`, `BagView.cs`, `ShopView.cs` | The three menus. |
| `ItemPickup.cs`, `TalismanUnlock.cs`, `VillageShop.cs` | In-world pieces. `OpenChest.cs` gained a one-time bonus item. |
| `FeatherFallTalisman.cs`, `CoinMagnetTalisman.cs` | The two new talisman types. `Talisman.cs` gained an icon, description, unlock hint and `OnTick`. |

- `PowerUpManager` now takes its slots from the saved loadout and updates them when the loadout changes.

**Talisman Holder**
- Open it with the **TALISMANS** pause button.
- It shows three equipped slots (Z/Square, X/Cross, C/Circle) above all six talismans.
- **Equipping:**
  - Press a talisman to equip it into a free slot, or press it again to take it off.
  - If all three slots are full, the talisman is picked up and the next slot you press is replaced.
  - Press a slot, then another slot, to swap them.
- Locked talismans show as "? ? ?" with a hint on how to find them.

| Talisman | Effect | How you get it |
|---|---|---|
| Water Breathing | Breathe underwater for 10 s | Equipped from the start |
| Spirit Dash | Dash through enemies | Equipped from the start |
| Super Jump | Much higher jump | Equipped from the start |
| Stone Skin | Immune to enemies for 6 s (reuses the old "Plain" asset) | Beat the Grave Warden |
| Feather Fall | Slow fall for 6 s | Beat the Sandscale Scarab |
| Coin Magnet | Pulls nearby coins in for 8 s | Beat the Yokai Warrior |

**Harvey's Bag**
- Open it with the **BAG** pause button, or straight from gameplay with Tab or Create/Select.
- It's a leather satchel with three tabs:
  - **Collectibles:** 10 maps, books and relics, placed in the hand-made levels, each replacing a coin.
  - **Power-ups & Misc:** Spirit Peach (+1 life) and Chi Crystal (refills chi), found in chests, plus an Old Compass keepsake.
  - **Village Goods:** Onigiri, Daruma Charm, Paper Lantern and Temple Postcard.
- Usable items are used from the bag, which handles the "already full" cases.

**Village shop**
- A stall sits in the Japan Village. Press Up or E to open it; Triangle is already Jump.
- Buying takes coins and saves. Shortfalls and items you already own are handled.

**Toasts:** a message appears when Harvey finds an item or a talisman.

**Content builder:** run **Tools → HNL → Build Talisman and Bag Content** (`Assets/Editor/HarveyMenusContentBuilder.cs`). It is safe to re-run.
- It imports the art, sets up the talisman and item assets and the catalog, and places the pickups, chest items, boss talisman rewards and the shop stall.
- The art comes from `Tools/UI/menus_art.py` and goes into `Assets/Sprites/UI/Menus`.
- A bug was found and fixed along the way: opening a scene unloads new assets, so references to them were saving as empty. The builder now reloads assets for each scene and repairs the broken pickups.

**Tested in Play mode** (with saving pointed at temporary storage, so the real save was untouched)
- Pause buttons, and Circle/Esc going back to the pause menu or the game.
- Equipping, replacing, swapping, removing and the locked case, with the live slots updating each time.
- Opening the bag with Select, tabs, and using items.
- The shop prompt, opening it with Up, and buying.
- Chest bonus items, world pickups and talisman unlocks.
- Coin Magnet collected 5 coins, and Feather Fall capped the fall speed at 1.6.
- The saved inventory reloads correctly.

## Request 3: tidy the pause menu and give it its own style

### What was asked
Clean up the pause menu and give it its own style, so it is nicely organised.

### What was done
- The 24 level pause menus were all plain scene copies: default buttons, LiberationSans font and uneven gaps. Z1A2 has no Quit button.
- New `Assets/Scripts/PauseMenuStyle.cs` restyles them when a level starts, so no scene needs hand edits:
  - a wood-and-gold card with a **PAUSED** plaque
  - a status row with coins, lives and the three equipped talismans
  - one evenly spaced column: Resume, Talismans, Bag, Main Menu, Quit
  - the main menu's button sprites and DOS font, with an icon on each button
  - the main menu's paw pointer, and a controls hint
- The pause code moved out of `HarveyMenus.cs` into this new file.
- The new art (pause card, plaque and five icons) was added to `Tools/UI/menus_art.py` and rendered. The catalog and builder were updated to include it.

### Finishing off (picked up in a later session)
- **Compile:** Unity compiled everything with no errors.
- **Builder:** **Tools → HNL → Build Talisman and Bag Content** was run. The catalog now holds the pause card (9-slice border 10), the plaque, the main menu's button plates and paw, and all five icons.
- **One fix after the first screenshot:** the third talisman gem hung over the right edge of the status plate. The gems moved 4 units left (`x = 20 + 16 * i`), and the LIVES text moved with them.

**Tested in Play mode** (no saving involved; nothing in pausing writes the save)
- **Z1A1:** five buttons, evenly spaced 20 units apart, in the order Resume, Talismans, Bag, Main Menu, Quit. Resume is selected first, with the paw beside it. Up/Down wrap around (Resume ↔ Quit).
- **Talismans and Bag buttons:** each hides the pause card and opens its menu. Closing returns to the pause card with a button selected.
- **Resume:** closes the menu and restores time scale 1.
- **Z1A2**, the level with no Quit button: four buttons, and the card shrinks to fit.
- No errors in the console.
