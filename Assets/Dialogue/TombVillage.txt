// ------------------------------------------------------------------ Professor Bastet, who runs the dig
== prof
-> cycle: prof_first, prof_again

== prof_first
Bastet: A cat in the dig site! Mind the trenches, we've only just levelled them.
I'm Professor Bastet. This camp has been digging out the Old Tomb for three seasons.
* What's inside the tomb? -> prof_tomb
* Any advice? -> prof_tip
* Just passing through. -> prof_bye

== prof_tomb
Bastet: Corridors, traps and something old that doesn't like visitors.
The workers call it the Grave Warden. I call it a very good reason to stay up here.
-> prof_tip

== prof_tip
Bastet: Take a lantern-light approach: slow down where it's dark.
And if you find a talisman down there, keep it. They're worth more than any pot.
-> prof_bye

== prof_again
Bastet: Back for more dust, {player}? The shop has fish if you're peckish.
-> end

== prof_bye
Bastet: Off you go then. Bring me a rubbing if you find one!
-> end
